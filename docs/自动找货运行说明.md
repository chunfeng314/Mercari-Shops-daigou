# 自动找货运行说明

## 浏览器和网络

- 从 Windows 正常环境运行 `start.ps1`。如果在受网络隔离的工具进程中启动，Chrome 可能出现 `ERR_NETWORK_ACCESS_DENIED`；这不等同于 VPN 配置错误。
- 默认使用工作台专用 Chrome，通过 Playwright 本地管道控制，登录状态存放在 `data/browser_profiles/`。正常任务无需反复允许接管日常 Chrome。
- 手动关闭专用窗口后，下一个任务会检查控制通道并在同一任务里重开浏览器。窗口关闭与 VPN 故障分别报告。
- 日常浏览器连接作为手动备用；服务重启后可能重新要求授权。

## 搜索和价格

- 闲鱼关键词来自对应日本商品的采集标题和说明，由本地词典生成；不需要先人工寻找中国商品链接。
- 先搜品牌、型号和规格，再使用去掉可选颜色/配饰限定词的宽泛查询；容量等型号信息保留。
- 页面常把价格小数放在独立元素中，例如 `¥ 189 .99`，按 `189.99` 解析。多商品页面的展示起价仍需与目标款核对。
- 搜索候选不等于已确认同款，容量、组合、成色和价格仍需核实。
- 结果先做品牌词、明确容量和必需配件筛选；冲突项保留排除原因，多商品页面提示目标款核价。搜索文字属性符合仍不能代替实物图、真伪和供货核验。

## 图片与来源

- 排除页头、头像、页尾及推荐商品流；保留商品详情和可见评论/晒单候选。
- 同一 CDN 图片的不同尺寸版本按同一素材去重，不靠变更尺寸凑足收图数量。
- 当页面明确只有一张商品图时，旧自动采集图若无法在当前商品图中核实，会被可恢复地排除。手工上传和已标记为评论区来源的候选不受这项历史清理影响。
- 排除图片保留文件和来源记录，可在货源页恢复；恢复后重新核对是否为实物图。排除图片不计入收图目标，也不能进入上架草稿。
- 收图目标仍为至少 5 张不同图片且包含实物图。某个货源只有 1 张时，应继续寻找有清楚来源的补充图片，不能把推荐区图片直接记成该货源的详情图。
